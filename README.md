## 핵심 방향

멍냥우편함은 동물 사진 SNS가 아니라 “조용한 이메일 우편 경험”을 목표로 합니다.

MVP에서 의도적으로 제외하는 기능:

- 댓글
- 팔로우
- 공개 피드
- 랭킹
- DM
- 실시간 채팅
- 인기순 추천

## MVP 한 줄 정의

승인된 동물 사진 한 장을 정기 이메일로 보내고, 수신자가 버튼 반응만 남길 수 있는 최소 서비스.

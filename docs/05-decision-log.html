1. 서비스 정체성

날짜: 2026-06-04

결정: 멍냥우편함은 동물 사진 SNS가 아니라, 귀여운 동물 사진을 이메일 우편처럼 받아보는 서비스로 정의합니다.

이유: 피드, 댓글, 랭킹 중심으로 가면 기존 SNS와 차별점이 약해지고 서비스 정서가 흐려집니다.

대안: 동물 사진 공유 SNS, 반려동물 커뮤니티, 사진 피드 서비스.

영향: 공개 피드, 댓글, 팔로우, 랭킹은 MVP에서 제외합니다.

상태: 확정

---

2. MVP 발송 주기

날짜: 2026-06-04

결정: 서비스 비전은 “매일 아침”으로 표현하되, MVP 운영은 주 3회 또는 테스트 그룹 대상 정기 발송으로 시작합니다.

이유: 매일 발송은 운영 부담과 콘텐츠 수급 부담이 큽니다. MVP에서는 경험 검증이 우선입니다.

대안: 처음부터 매일 발송, 사용자가 직접 빈도 선택, 비정기 발송.

영향: 랜딩 문구는 “아침 우편” 정서를 유지하되, 신청 시 실제 발송 주기를 명확히 안내해야 합니다.

상태: 추천 확정안

---

3. 콘텐츠 검토 방식

날짜: 2026-06-04

결정: MVP에서는 운영자 수동 검토를 기본으로 합니다. AI 자동 검토는 보조 기능 또는 이후 단계로 둡니다.

이유: 사진 권리, 부적절 이미지, 동물 학대 의심 이미지는 자동 판정만으로 처리하기 어렵습니다.

대안: 완전 자동 필터링, 신고 후 사후 처리만 하기.

영향: 운영자 검토 화면이 MVP 1순위에 포함됩니다.

상태: 확정

---

4. 반응 방식

날짜: 2026-06-04

결정: 자유 댓글 대신 3~5개 버튼 반응만 제공합니다.

이유: 댓글은 커뮤니티화와 갈등, 평가 부담을 만듭니다. 버튼 반응은 우편을 잘 받았다는 가벼운 신호로 충분합니다.

대안: 좋아요 1개만 제공, 자유 댓글 제공, 이모지 반응 제공.

영향: 반응은 공개 랭킹이나 인기순 정렬에 사용하지 않습니다.

상태: 확정

---

5. 익명성

날짜: 2026-06-04

결정: 업로드자는 특정 수신자를 알 수 없고, 수신자는 업로드자의 상세 프로필을 보지 않습니다.

이유: 관계 형성보다 조용한 우편 경험이 핵심입니다. 사용자 간 연결을 열면 DM/팔로우/커뮤니티로 확장될 가능성이 커집니다.

대안: 닉네임 공개, 프로필 공개, 팔로우 허용.

영향: MVP에서는 상세 프로필과 사용자 간 연결 기능을 제외합니다.

상태: 확정

보류 결정

닉네임 표시 여부

상태: 보류

사진 설명에 업로드자 닉네임을 표시할지 아직 결정하지 않습니다. 표시하더라도 팔로우/프로필로 이어지지 않게 해야 합니다.

발송 자동화 수준

상태: 보류

MVP 초기에는 mock 또는 테스트 발송으로 검증하고, 실제 자동 발송은 운영자 승인 흐름이 준비된 후 결정합니다.

AI 이미지 검토 보조

상태: 보류

AI 검토는 안전 보조로 쓸 수 있지만, MVP 핵심 기능은 아닙니다. 자동 삭제 결정을 AI에 맡기지 않습니다.

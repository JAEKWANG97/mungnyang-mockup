# 멍냥우편함 서비스 기획

멍냥우편함은 SNS 피드 없이, 귀여운 동물 사진을 정기 이메일 우편처럼 받아보고, 댓글 대신 버튼 반응만 남기는 익명 동물 사진 우편 서비스입니다.

## 핵심 정의

멍냥우편함의 핵심은 “우리 애 자랑 피드”가 아니라, 내가 발견한 작은 귀여움을 누군가의 하루 시작에 조용히 보내는 경험입니다.

## 핵심 가치

사용자는 누군가가 올린 귀여운 동물 사진을 피드에서 계속 소비하는 것이 아니라, 아침 또는 정해진 시간에 우편처럼 받아봅니다.

서비스가 만들고 싶은 감정은 다음에 가깝습니다.

- 오늘 아침 작은 귀여움이 도착했다.
- 내가 올린 사진이 누군가의 하루를 조금 좋게 만들었다.
- 댓글과 평가 없이 가볍게 반응만 남겼다.

## MVP 사용자

### 수신자

- 이메일 수신에 동의합니다.
- 정해진 주기에 동물 사진 한 장을 받습니다.
- 댓글 대신 버튼 반응만 남깁니다.

### 업로드자

- 자기 반려동물 또는 사용권이 있는 동물 사진을 올립니다.
- 사진에 짧은 설명을 붙일 수 있습니다.
- 누가 받는지는 알 수 없습니다.
- 받은 사람들의 익명 버튼 반응 정도만 확인합니다.

### 운영자

- 부적절 이미지, 무단 이미지, 신고 사진을 관리합니다.
- 이메일 발송 실패와 수신거부를 관리합니다.
- 서비스 톤과 정책을 유지합니다.

## 서비스가 피하려는 방향

멍냥우편함은 동물 사진 서비스이지만, 일반적인 SNS가 되지 않는 것을 중요하게 봅니다.

MVP에서 제외하는 방향은 다음과 같습니다.

- 공개 피드
- 댓글
- 팔로우
- 랭킹
- DM
- 실시간 채팅
- 인기순 추천
- 자동 SNS 공유

## 검증 질문

- 이 서비스는 SNS처럼 보이지 않는가?
- 받은 사람이 부담 없이 반응할 수 있는가?
- 업로드자가 평가 경쟁을 느끼지 않는가?
- 이메일이 스팸/광고처럼 보이지 않는가?
- 무단 이미지와 부적절 이미지를 막을 수 있는가?
- 운영자가 신고/숨김/발송 실패를 처리할 수 있는가?

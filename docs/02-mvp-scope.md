# MVP 범위

## MVP 한 줄 정의

MVP는 승인된 동물 사진 한 장을 정기 이메일로 보내고, 수신자가 버튼 반응만 남길 수 있는 최소 서비스입니다.

## MVP 목표

MVP의 목표는 기능이 많은 서비스를 만드는 것이 아닙니다.

검증하려는 핵심 질문은 다음입니다.

> 사람들은 귀여운 동물 사진을 피드가 아니라 이메일 우편처럼 받아보는 경험을 계속 원할까?

## 핵심 가설

### 1. 수신 경험

사용자는 앱에 들어가 피드를 소비하지 않아도, 이메일로 도착한 귀여운 동물 사진 한 장에 만족할 수 있습니다.

검증 지표:

- 이메일 오픈율
- 버튼 반응률
- 수신 유지율
- 수신거부율

### 2. 업로드 경험

업로드자는 공개 피드나 댓글이 없어도, 익명 반응만으로 사진을 올릴 이유를 느낄 수 있습니다.

검증 지표:

- 사진 업로드 수
- 재업로드율
- 반응 확인율

### 3. 운영 가능성

운영자는 복잡한 자동화 없이도, 수동 검토와 기본 신고 흐름으로 안전한 사진 우편 경험을 유지할 수 있습니다.

검증 지표:

- 승인 대기 시간
- 신고율
- 부적절 이미지 처리 시간
- 발송 실패율

## MVP 포함 기능

### 수신 신청

- 이메일 입력
- 수신 동의 체크
- 발송 주기 안내
- 수신거부 안내

MVP에서는 OAuth 로그인을 필수로 두지 않고, 이메일만으로 테스트 가능하게 시작합니다.

### 사진 업로드

- 사진 업로드
- 짧은 설명 입력
- 직접 촬영/사용권 확인 체크
- 콘텐츠 정책 동의
- 검토 상태 표시

한 번에 여러 장 업로드, 사진 편집, 필터 기능은 제외합니다.

### 운영자 검토

- 업로드 사진 목록
- 승인
- 숨김
- 반려
- 신고 사진 확인

MVP에서는 완전 자동 검열보다 운영자 수동 검토를 우선합니다. AI 검토는 후순위 보조 기능입니다.

### 이메일 발송

- 승인된 사진 중 하나 선택
- 이메일 템플릿 생성
- 테스트 발송 또는 mock 발송
- 실제 발송 전 승인
- 발송 성공/실패 기록

컨셉은 “매일 아침”이지만, MVP 운영은 주 3회 또는 테스트 그룹 발송으로 시작합니다.

### 버튼 반응

- 수신 이메일에서 반응 버튼 클릭
- 반응 저장
- 업로드자에게 익명 누적 반응 제공

허용 반응 예시:

- 귀여워요
- 아침이 좋아졌어요
- 또 보고 싶어요
- 웃겼어요
- 따뜻해요

### 기본 신고

- 수신자가 사진 신고 가능
- 신고된 사진 임시 숨김 가능
- 운영자 검토 후 유지/숨김/삭제 결정

## MVP 제외 기능

### 커뮤니티 기능 제외

- 댓글
- 대댓글
- DM
- 팔로우
- 공개 프로필
- 사용자 간 대화

### 피드/랭킹 기능 제외

- 공개 피드
- 인기 사진
- 랭킹
- 좋아요 순 정렬
- 추천 탭
- 무한 스크롤

### 과한 개인화 제외

- 복잡한 추천 알고리즘
- 취향 기반 세분화
- AI 개인화 편지
- 사용자 행동 기반 타겟팅

### 운영 자동화 제외

- 완전 자동 이미지 삭제
- 무승인 대량 이메일 발송
- 비용 발생 외부 서비스 자동 연동

## MVP 완료 기준

- 수신자가 이메일 수신 신청을 할 수 있다.
- 업로드자가 사진과 짧은 설명을 등록할 수 있다.
- 운영자가 사진을 승인/숨김/반려할 수 있다.
- 승인된 사진만 발송 후보가 된다.
- 수신자에게 이메일 mock 또는 테스트 발송이 가능하다.
- 수신자는 버튼 반응을 남길 수 있다.
- 반응은 익명 누적 형태로 저장된다.
- 수신거부 흐름이 존재한다.
- 신고된 사진은 운영자 검토 대상으로 전환된다.

멍냥우편함
기획 문서

SNS 없이 귀여운 동물 사진을 정기 이메일 우편처럼 받아보고, 댓글 대신 버튼 반응만 남기는 익명 동물 사진 우편 서비스입니다.

핵심 방향

멍냥우편함은 “동물 사진 SNS”가 아니라 “조용한 이메일 우편 경험”을 목표로 합니다. 공개 피드, 댓글, 팔로우, 랭킹을 의도적으로 제외해 평가 경쟁보다 작은 위로와 가벼운 반응에 집중합니다.

업로드자 사진 등록
→ 운영자 검토
→ 승인 사진이 발송 후보가 됨
→ 수신자에게 정기 이메일 발송
→ 수신자가 버튼 반응
→ 업로드자는 익명 누적 반응 확인
